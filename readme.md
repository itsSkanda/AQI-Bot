# SkySense: Intelligent Air Quality Prediction

SkySense is a web-based air quality monitoring and prediction platform combining machine learning, real-time AQI data and interactive visualization.

## Features

- CNN architecture for sky image based prediction
- Real-time city-wise AQI monitoring
- WAQI API integration
- Flask backend
- Interactive Chart.js visualization
- Air quality chatbot
- Responsive web interface

## Technologies

- Python
- TensorFlow / Keras
- CNN
- Flask
- WAQI API
- Chart.js

## Installation

pip install -r requirements.txt

## Run

python app.py

Open:

http://127.0.0.1:5000

## WAQI API

Set your WAQI API token as an environment variable:

WAQI_TOKEN=your_token
